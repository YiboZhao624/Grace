The open-domain data can be downloaded from the following links:

1. 2wikimultihop: https://www.dropbox.com/s/npidmtadreo6df2/data.zip

2. hotpotQA: running the `download.sh` script in the hotpotQA folder will download the data.

3. musique: https://drive.google.com/file/d/1tGdADlNjWFaHLeZZGShh2IRcpO6Lv24h/view?pli=1

please just unzip the data and put them into the corresponding folders. The other processing is done in the `dataset.py` script.

The specific domain data can be downloaded from the following links:

1. QASPER: download the data from the following urls:

Train and Dev data: https://qasper-dataset.s3.us-west-2.amazonaws.com/qasper-train-dev-v0.3.tgz

Test data: https://qasper-dataset.s3.us-west-2.amazonaws.com/qasper-test-and-evaluator-v0.3.tgz

2. PeerQA: from the Github page of PeerQA: https://github.com/ukplab/peerqa
